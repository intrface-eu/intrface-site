# @intrface/convex

Intrface backend — Convex realtime database, serverless functions, and email orchestration.

## Getting Started

1. **Configure environment variables**
   ```bash
   cp .env.example .env
   # Add your Convex deploy key and Resend API key
   ```

2. **Start the dev server** (from monorepo root)
   ```bash
   bun dev:convex
   # or run all services together
   bun dev
   ```

3. **Deploy to production**
   ```bash
   bunx convex deploy
   ```

## Structure

- `convex/schema.ts` — Database schema (contact submissions, etc.)
- `convex/email.ts` — Resend integration for transactional email
- `convex/_generated/` — Auto-generated by `convex dev`

## Email

Contact form submissions are stored in the `contactSubmissions` table. The `sendContactEmail` action is ready to wire into Resend once you add `RESEND_API_KEY` to your Convex dashboard.
